## Known limitations

- Git commits and a clean worktree are impossible under the current read-only `.git` mount.
- JSON Schema validation is a documented subset, not full draft compliance; `$ref`, formats, conditionals and draft vocabularies are not supported.
- JSON array diffing is index-based and does not infer moved elements.
- Cron UI intentionally rejects names and extended Quartz/EventBridge syntax.
- HTTP lookup is a curated common standardized-code reference, not every registered extension.
- Construction outputs are planning estimates and do not claim structural or universal code compliance.
