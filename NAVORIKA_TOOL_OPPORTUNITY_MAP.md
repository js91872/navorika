# Navorika Tool Opportunity Map

This planning map is based only on the current repository and obvious gaps in established topic clusters. These are architecture/topic opportunities, not measured SEO opportunities. No search volume, keyword difficulty, traffic estimate, or external SERP dataset was provided. Validate demand, implementation feasibility, and overlap before development.

Do not implement these ideas as bulk programmatic pages. Each approved tool must pass the growth playbook’s utility and quality gates.

## Tier 1 — High priority

These deepen clusters where Navorika already has several working tools and clear internal workflows.

### Construction materials and estimating

- Mortar calculator — connect brick, cement, and sand estimates.
- Concrete block calculator — extend masonry planning beyond bricks.
- Drywall/sheetrock calculator — strengthen home finishes and contractor estimates.
- Decking board calculator — add a practical surface-material workflow.
- Mulch/topsoil calculator — extend volume/material planning from gravel and excavation.
- Construction waste/dumpster estimator — complement material and project-cost estimates.

### Finance planning

- Lumpsum investment calculator — pair with SIP and investment-return profiling.
- CAGR calculator — provide a focused comparable-return measure.
- Compound interest calculator — establish a general method behind multiple investment tools.
- Savings goal calculator — connect budgeting to retirement and investment planning.
- Mortgage affordability calculator — connect EMI, amortization, and cash flow.

### Image optimization

- Aspect ratio calculator — connect resize, crop, and social presets.
- Image file-size estimator — help choose dimensions, format, and compression before export.
- Responsive `srcset` generator — connect image optimization to web publishing.

### Developer data workflows

- URL encoder/decoder — complement Base64 and UTM workflows.
- UUID generator/validator — add a focused identifier utility.
- Hash generator/checksum tool — complement browser crypto without implying encryption.
- YAML/JSON converter — extend the structured-data cluster if a robust parser can be maintained safely.

## Tier 2 — Expansion

These are useful adjacent topics that could broaden authority after Tier 1 workflows are strong.

### Construction

- Stair calculator
- Ramp slope calculator
- Lumber/board-foot calculator
- Insulation calculator
- HVAC room-load planning estimator, only with carefully scoped assumptions and professional-review boundaries
- Rainwater harvesting calculator connecting roof area and tank capacity

### Finance

- Debt payoff/snowball calculator
- Credit-card payoff calculator
- Emergency-fund calculator
- Break-even calculator
- Profit margin/markup calculator
- Inflation-adjusted return calculator

### Developer and networking

- CIDR subnet calculator
- IPv4 subnet mask calculator
- Wildcard mask calculator
- IP address converter
- DNS record lookup, only with a clearly disclosed live data source and caching strategy
- Cron expression explainer

A networking group should launch as a coherent cluster, not as one isolated thin page. CIDR, subnet mask, wildcard mask, and IP conversion have a natural workflow if implemented comprehensively.

### Health and fitness

- Macronutrient calculator connected to calories, BMR, and TDEE
- Pace calculator connected to walking/running calorie estimates
- One-rep max calculator with clear population and safety limitations
- Hydration planning estimator with conservative health disclaimers

### PDF and documents

- PDF page-size inspector
- PDF/A readiness checker, only if the implementation can reliably validate the claimed requirements
- Scan page cleanup tool for rotation, crop, and contrast, if browser performance remains acceptable

## Tier 3 — Experimental

Validate the task, differentiation, maintenance cost, and safety before committing engineering time.

- Solar payback estimator requiring current tariffs, incentives, and regional assumptions
- Building-code lookup or compliance assistant, because rules are location-specific and change over time
- Portfolio allocation visualizer, because suitability language and financial-risk presentation need careful review
- Tax regime comparison tools tied to a specific jurisdiction and tax year
- Nutrition label analyzer, because parsing quality and health interpretation can create misleading output
- OCR document extractor, because large browser models may create performance and accuracy trade-offs
- Color-accessibility simulator beyond deterministic contrast calculations
- Security header scanner requiring external network requests and abuse controls
- Cloud cost calculators, because provider prices and product structures change frequently
- AI-assisted document/image transformations, because privacy, cost, quality, and dependency behavior must be explicit

## Prioritization checklist

For each candidate, score evidence—not intuition—across user task clarity, overlap with existing routes, cluster contribution, implementation correctness, authoritative-source availability, maintenance burden, safety, performance, and internal workflow value. External SEO data can be added later as a separate evidence column; never retrofit invented metrics into this map.
